# v1.20.1 Session Header / Unit Graphic Cleanup

## What changed

- Hides the global top header during active revision/test/class-note sessions.
- Adds a compact session hero with:
  - Back to revision hub
  - Reaction branding
  - current unit name / mode
  - current unit graphic strip
  - session progress counter
- Removes repeated unit/progress chips from the question card.
- Keeps question cards focused on the current question and answer choices.

## Design intent

The hub keeps the full app header. Sessions use a focused header so the learner sees only the context needed for the current revision card.

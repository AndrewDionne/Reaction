# Class Notes Enhancement Patch v1.10.0

## Purpose

This patch improves the class-note layer introduced in v1.9.0. Each class note is expanded so the “Study this” route gives a more useful explanation when a student does not understand a card.

## Added to notes

Each of the 25 notes now includes:

- deeper explanation
- memory hook
- quick self-check
- useful answer sentence starter
- follow-up practice prompt
- expanded key points where useful

## UI changes

The class-note view now renders the new sections:

- Big idea
- Deeper explanation
- Key points
- Memory hook
- Common mistakes
- Worked / model example
- Quick self-check
- Useful answer sentence
- Try next

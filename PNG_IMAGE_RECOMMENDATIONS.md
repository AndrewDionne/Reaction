# PNG Image Recommendations

This file lists the areas where PNG images would likely work better than SVGs in the Year 9 Science study app.

## When PNG is better than SVG

Use PNG rather than SVG when the image depends on:

- photographic realism
- soft shading or gradients that would look clunky in flat vector form
- microscope-style views
- textured materials
- complex apparatus with many small details
- layered screenshots or worksheet-style scans that should keep their original visual feel

## Recommended visual requirements

### Style
- clean educational style
- uncluttered background
- one main concept per image
- strong contrast for labels
- readable at laptop and tablet size

### Technical requirements
- format: PNG
- color mode: sRGB
- export width: 1400–1800 px
- file size target: under 400 KB if possible, under 700 KB maximum
- background: white or transparent depending on placement
- margin: leave safe margins around the subject for responsive scaling

### Labeling requirements
- short labels only
- use arrows or simple callouts
- avoid dense paragraphs inside the image
- keep minimum text size visually readable when the image is displayed at roughly 700–900 px wide

### Naming convention
- `9A-triceratops-evidence.png`
- `9B-root-hair-micrograph.png`
- `9E-material-textures.png`
- `9F-blast-furnace-overview.png`
- `9J-circuit-components-photo.png`

### Accessibility requirements
For each PNG added to the app, include:
- an `alt` text string
- a short caption
- a card link or topic link so the image only appears where it supports learning

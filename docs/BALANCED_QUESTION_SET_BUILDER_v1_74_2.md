# v1.74.2 — Balanced question set builder

## What changed
- Revision journey and Test your knowledge now have a **Number of questions** selector.
- Available choices are **10**, **20**, **30**, **40**, and **All**.
- The main start button uses the selected session size rather than always launching the full filtered deck.

## Question mix behaviour
- Smaller sets are built from the selected units/sub-units.
- The builder prioritises new questions and includes a smaller share of questions marked **Revisit**.
- Questions used recently in the same mode are deprioritised so repeated reviews feel fresher.

## All-material balance
When no unit, sub-unit, type, level or search filter is active, the builder balances the generated set across:

- Biology: 9A and 9B
- Chemistry: 9E and 9F
- Physics: 9I and 9J

## Safety notes
- Test your knowledge still hides answers, explanations and class-note links until the test is submitted.
- The full filtered card count remains visible so students can see the available pool before choosing a smaller set.

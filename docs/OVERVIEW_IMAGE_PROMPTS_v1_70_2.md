# Overview image prompts v1.70.2

These are the remaining overview-image gaps after the overview rewrite and cleanup passes.

## Standard for all overview explainer images

- Create **one** clean high-quality educational science image for a Year 9 revision app.
- Purpose: **overview explainer image** shown full width inside an expanded checklist item.
- Size: **1600x1000 landscape**.
- The text inside the image must be readable at normal body-text size on screen.
- Keep wording short and simple.
- Prefer **3 to 5 large panels** rather than one dense poster.
- Use clean textbook-style diagrams, not rich concept art.
- Do **not** include question wording such as “state”, “identify”, or “explain” in the image.
- Do **not** make the image a contact sheet.

## 1) 9A conservation methods overview

**Target file**: `assets/webp/9A-conservation-methods-overview.webp`

**Why needed**
The current overview still lacks a simple full-width image that clearly compares the main conservation methods.

**Prompt**
Create one clean high-quality educational science image for a Year 9 revision app.
This is an overview explainer image, not a question image.
The image size must be 1600x1000 landscape.

Subject: conservation methods for biodiversity.

The image should show 4 large panels laid out clearly from left to right:
1. protected habitat / nature reserve
2. seed bank
3. captive breeding programme
4. breeding and release back into the wild

Each panel should have:
- a short title
- one clear simple diagram
- one short support line only

Key teaching points to include:

- seed banks store plant genetic material
- captive breeding increases numbers of endangered species
- release programmes can return species to the wild

Avoid:
- dense paragraphs
- tiny labels
- more than 4 panels
- decorative background clutter

## 3) 9F extraction decision overview

**Target file**: `assets/webp/9F-extraction-decision-overview.webp`

**Why needed**
The current extraction visuals are still too dense for overview use.

**Prompt**
Create one clean high-quality educational science image for a Year 9 revision app.
This is an overview explainer image.
The image size must be 1600x1000 landscape.

Subject: choosing how a metal is extracted.

The image should show a simple decision flow based on the reactivity series.

Required structure:
- top banner: “How do we extract a metal?”
- centre visual: short reactivity strip with carbon clearly marked
- left branch: metals below carbon → reduction with carbon
- right branch: metals above carbon → electrolysis
- example box for iron below carbon
- example box for aluminium above carbon

Key teaching points to include:
- more reactive metals need more energy to extract
- if the metal is less reactive than carbon, reduction with carbon can be used
- if the metal is more reactive than carbon, electrolysis is needed

Avoid:
- a full crowded reactivity series with many metals
- long extraction descriptions
- blast furnace details in this image

## 4) 9F metal reaction products overview

**Target file**: `assets/webp/9F-metal-reaction-products-overview.webp`

**Why needed**
There is still no clean full-width overview image that compares the common products formed in metal reactions.

**Prompt**
Create one clean high-quality educational science image for a Year 9 revision app.
This is an overview explainer image.
The image size must be 1600x1000 landscape.

Subject: products of metal reactions.

Use a 3-panel layout:
1. metal + oxygen → metal oxide
2. metal + water → metal hydroxide + hydrogen (or a simpler note that some metals react slowly)
3. metal + acid → salt + hydrogen

Each panel should show:
- a simple reaction word equation
- one clear example

Examples to use:

- full symbol equations everywhere
- dense safety notes
- too many examples in one panel

## 5) 9J wire resistance investigation overview

**Target file**: `assets/webp/9J-wire-resistance-overview.webp`

**Why needed**
The overview needs a simpler practical-investigation image that shows the key variables clearly.

**Prompt**
Create one clean high-quality educational science image for a Year 9 revision app.
This is an overview explainer image.
The image size must be 1600x1000 landscape.

Subject: investigating resistance in a wire.

The image should have 3 main zones:
1. the circuit setup
2. the variable being changed
3. the variables kept the same

Required content:
- power supply
- ammeter in series
- voltmeter across the test wire
- test wire clearly highlighted
- one slider or labelled comparison showing wire length changing
- a small box showing “calculate resistance: R = V / I”

Key teaching points to include:
- independent variable: wire length
- dependent variable: resistance
- control variables: material and thickness of wire
- longer wire gives higher resistance

Avoid:
- a very crowded practical worksheet look
- too many circuit labels
- answer-leak multiple-choice formatting

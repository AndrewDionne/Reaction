# v1.73.6 — Describe hint language refinement

## Summary

This patch refines the **Describe** written-answer guidance so it works for linked science ideas as well as graph or pattern questions.

## Changes

- Changed Describe guidance from change-only language to a broader linked-points structure.
- Updated the compact in-question Describe format to:
  - First: science point
  - Then link: linked detail
  - Finally: final detail / evidence
- Updated the written-answer help pop-out quick choice wording.
- Kept Identify and Explain guidance unchanged.

## Rationale

Describe questions are not always about a trend or visible change. They can also ask students to connect related science ideas in a clear order, such as describing how chromosomes, DNA and genes are linked together.

# Unit study cards restore v1.72.4

## Problem

The homepage no longer made the unit-level study entry points clear enough. Students need visible unit cards with direct access to both the unit overview and class notes.

## Fix

Each unit card now has two prominent study actions near the top of the card:

- **Unit overview** — opens the targeted unit learning checklist.
- **Class notes** — opens a unit note chooser listing the class notes available for that unit.

The existing sub-unit rows and per-objective **Class Notes** buttons are still available below the unit actions.

- `styles.css`

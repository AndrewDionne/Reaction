# v1.73.4 — Compact question-type hint cards

This patch keeps written-question support available without taking over the answer card.

## Changed

- The in-test **Question type** button now opens a compact hint card.
- The card shows:
  - the detected type: **Identify**, **Describe**, or **Explain**
  - simple clue wording for that type
  - what a good answer should do
  - a decomposed answer-format sentence with labelled blanks
- The larger teaching guide remains in the **How to answer written questions** pop-out from the learning-mode panel.

## Intended student flow

1. Read the question.
2. Press **Question type** only if unsure how to structure the written answer.
3. Use the one-line format hint.
4. Write the answer in the text box.

## Scope

No content-bank, question-ID, unit-overview, class-note, or exam-paper data was changed.

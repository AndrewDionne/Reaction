# v1.73.2 — Simplified written-answer formats

This patch simplifies GCSE-style open written-answer guidance into three student-facing types.

## Typology

1. **Identify**
   - Covers: state, name, label, which, where, what is.
   - Good answer: a short, precise science word, phrase or fact.
   - Shape: `The answer is ____.`

2. **Describe**
   - Covers: what happens, what changes, pattern, trend, use the graph/table.
   - Good answer: clear observations or a pattern, using data/labels if given.
   - Shape: `As ____ changes, ____ changes. The evidence is ____.`

3. **Explain**
   - Covers: why, how, give a reason, suggest, compare.
   - Good answer: point → reason → result, linked with because/so/therefore.
   - Shape: `____ happens because ____. This means ____.`

## App behaviour

- Open-answer questions in **Test your knowledge** no longer show the old `Cue:` line.
- They now show a **Question type** button.
- Pressing the button shows the likely type and a short answer strategy.
- Unit overviews now include a compact **How to answer written questions** class-note section.
- Written-answer practice cards use the same simplified question-type strategy.

# v1.73.8 — Describe short-sentence strategy

This patch refines the written-answer support for **Describe** questions.

## Behaviour changed

- The compact **Question type** hint now frames Describe answers as a sequence of short descriptive sentences.
- The larger **How to answer written questions** pop-out uses the same language.
- The Describe pitfall now explicitly says that if a question asks **why**, it is an **Explain** question.

## Student-facing strategy

**Describe** means:

1. Write one short sentence for the first science point.
2. Write another short sentence linking it to the next science point.
3. Add a final detail, observation, value, or evidence.

This is intended to keep Describe answers precise and stop students drifting into long explanation-style answers unless the question asks why.

## Not changed

- Identify format is unchanged.
- Explain format is unchanged.
- Existing questions, IDs, notes, overviews, and exam bank data are unchanged.

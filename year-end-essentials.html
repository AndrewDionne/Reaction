Year-end essentials study pack

This checklist is built around the topics and wording patterns that repeat across the source-style practice exams. Use it before building a normal 80-mark paper.

How to use this page

1. Learn the essentials

Use each topic block as a checklist. Anything unclear should become a revision target.

2. Practise source wording

The exams ask short state/name/identify questions plus longer explain/describe questions.

3. Build a normal paper

Open the exam builder and use the normal 80-mark papers that match the expected format.

Section A: Biology essentials

Expected style: short recall, labelled structures, adaptations, equations, food tests and short explanations.

repeatedmust know

Cells, microscopy and organisation

Open class notes

Plant/animal cell structures, cell functions, tissues, organs and magnification are repeated source-exam ideas.

Must know

  • Nucleus controls cell activities and contains genetic information.
  • Mitochondria release energy by respiration.
  • Plant-only structures: cell wall, chloroplasts and permanent vacuole.
  • Tissue = group of similar cells working together.
  • Organ system = organs working together.

Exam wording

  • Name two structures found in plant cells but not animal cells.
  • Describe the function of the nucleus.
  • Calculate magnification = image size ÷ actual size.
Model answer move

For adaptations, name the feature then link it to the function: “large surface area so more water can be absorbed.”

repeated

Photosynthesis, respiration and plant transport

Open class notes

Expect equations, limiting factors, root hair cells, xylem and gas exchange through stomata.

Must know

  • Photosynthesis: carbon dioxide + water → glucose + oxygen.
  • Photosynthesis needs light energy and chlorophyll.
  • Limiting factors: light intensity, carbon dioxide concentration and temperature.
  • Respiration releases energy for cell processes.
  • Xylem carries water and mineral ions from roots to leaves.

Exam wording

  • Write the word equation for photosynthesis.
  • Explain why the rate levels off on a graph.
  • Explain how a root hair cell is adapted for absorption.
repeated

Digestion, enzymes and food tests

Open class notes

Food tests and digestion are repeated in the source papers and should be treated as year-end essentials.

Must know

  • Iodine tests for starch: orange-brown to blue-black.
  • Benedict’s tests for reducing sugar: blue to brick-red/orange when heated.
  • Biuret tests for protein: blue to purple/lilac.
  • Enzymes have an optimum temperature and pH.
  • Above the optimum, enzymes denature and the active site changes shape.
  • The small intestine absorbs digested nutrients into the blood.

Exam wording

  • Name the food test used for starch.
  • State the positive colour change.
  • Explain why enzyme activity falls at high temperature.

Section B: Chemistry essentials

Expected style: particle/atomic recall, word equations, simple calculations, acids/alkalis and safety.

repeated

Atoms, elements, compounds and the periodic table

Open class notes

Source papers repeatedly ask for simple atomic structure and periodic table reasoning.

Must know

  • Element = one type of atom only.
  • Compound = two or more different elements chemically joined.
  • Proton charge = +1, neutron = 0, electron = -1.
  • Atomic number = number of protons.
  • Mass number = protons + neutrons.
  • Same group elements have the same number of outer-shell electrons.

Exam wording

  • State the number of protons, neutrons and electrons.
  • Explain why elements in the same group have similar properties.
  • Name the compound made when magnesium reacts with oxygen.
repeated

Acids, alkalis, reactions and safety

Open class notes

The normal papers should practise acid reactions, neutralisation, observations and safety precautions.

Must know

  • Neutral solution has pH 7.
  • Acids have pH below 7; alkalis have pH above 7.
  • Acid + metal → salt + hydrogen.
  • Acid + alkali → salt + water.
  • Acid + carbonate → salt + water + carbon dioxide.
  • Hydrogen test: lit splint gives a squeaky pop.
  • Carbon dioxide test: turns limewater cloudy.

Exam wording

  • Complete the word equation.
  • Name the gas produced.
  • State one safety precaution when using acids.
repeatedcalculation

States of matter, particles and density

Open class notes

These questions usually mix particle descriptions with one density calculation.

Must know

  • Solid: particles closely packed and vibrating in fixed positions.
  • Liquid: particles close together but able to move past each other.
  • Gas: particles far apart and moving quickly.
  • Gases compress because particles are far apart.
  • Diffusion happens faster at higher temperature because particles move faster.
  • Density = mass ÷ volume.

Exam wording

  • Describe the particle arrangement in a solid.
  • Explain why gases can be compressed.
  • Calculate density using mass and volume.

Section C: Physics essentials

Expected style: equations, graph interpretation, circuits, energy resources and waves/light/sound.

repeatedcalculation

Forces, motion and graphs

Open class notes

Speed and graph questions repeat strongly across source-style papers.

Must know

  • Speed = distance ÷ time.
  • Gradient of a distance-time graph = speed.
  • Horizontal distance-time line = stationary.
  • Balanced forces produce no change in motion.
  • Unbalanced forces cause acceleration, deceleration or change of direction.

Exam wording

  • State the speed equation.
  • Calculate average speed.
  • Interpret the gradient or a horizontal section of a graph.
repeated

Energy resources, transfers and electricity

Open class notes

Expect renewable resources, energy transfer wording, series circuits and voltage/current questions.

Must know

  • Renewable examples: solar, wind, hydroelectric, tidal, wave, geothermal.
  • Non-renewable examples: coal, oil, gas, nuclear fuel.
  • Energy cannot be created or destroyed; it is transferred or stored.
  • Current is a flow of charge.
  • Ammeter goes in series; voltmeter goes in parallel.
  • In a series circuit, removing one lamp breaks the circuit.

Exam wording

  • Name two renewable energy resources.
  • State what a voltmeter measures.
  • Explain what happens if one bulb is removed from a series circuit.
repeated

Waves, light and sound

Open class notes

This is a repeated source-exam area that needs normal-paper practice even if it is not a core 9A/9B/9E/9F/9I/9J unit page.

Must know

  • Wave speed = frequency × wavelength.
  • Sound needs particles and cannot travel through a vacuum.
  • Light can travel through a vacuum.
  • Reflection = bouncing off a surface.
  • Refraction = change of direction when entering another medium.
  • White light can be dispersed into a spectrum by a prism.
  • Higher pitch means higher frequency.

Exam wording

  • State the wave speed equation.
  • Explain why sound cannot travel through a vacuum.
  • Describe what happens when white light passes through a prism.

Section D: Working scientifically essentials

Expected style: graph plotting, interpreting trends, variables, controls, repeats, anomalies and safety.

repeatedgraph

Graph plotting and interpretation

Open class notes

The source exams consistently include a graph grid or data table.

Must know

  • Use a suitable scale that fills the graph grid.
  • Plot points accurately using small crosses or dots.
  • Draw a line of best fit when the data shows a trend.
  • Use the graph to estimate values between plotted points.
  • Describe trends using both variables.

Exam wording

  • Plot the data on the graph grid.
  • Describe the trend shown.
  • Use the graph to estimate a value.
repeatedpractical

Variables, controls, repeats and safety

Open class notes

Practical-method questions appear in both source-style papers.

Must know

  • Independent variable = what is changed.
  • Dependent variable = what is measured.
  • Control variables = kept the same for a fair test.
  • Repeats improve reliability and help spot anomalies.
  • Safety answers must name the hazard and the precaution.

Exam wording

  • Identify the independent variable.
  • State two control variables.
  • Suggest one safety precaution.
  • Explain why repeats are useful.
